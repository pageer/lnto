# Runtime requirements — shared by local dev and production host.
#
# History: the original pins (see git) were Flask 2.0.1-era and worked on the
# host's old Python 3.9. When the host moved to Python 3.11 and the local
# machine to 3.14/3.15, those pins became unbuildable (Werkzeug 2.0.1 uses
# ast.Str, removed in Python 3.12; Flask-Login 0.5 imports a Werkzeug API
# removed in 2.1). The set below is the closest modern combination that runs
# unchanged on both Python 3.11 and 3.15.
#
# Notes:
# - PyMySQL is the DB driver. Locally the app uses SQLite (default
#   SQLALCHEMY_DATABASE_URI), so PyMySQL is simply unused; on the host,
#   config.py uses the mysql+pymysql:// scheme. Pure Python, installs
#   everywhere — no MySQL headers needed.
# - SQLAlchemy stays on 1.4.x: the models use the 1.4 Query API.
# - Jinja2 3.1.x pairs with MarkupSafe 3.x. Do NOT bump Flask/Werkzeug/SQLAlchemy
#   requirements-dev.txt and the old requirements files in git history.
# - Dev tools (pylint etc.) live in requirements-dev.txt; greenlet is not
#   needed (no asyncio).
